🚗 СЛАЙД 2: Задание №1 — Автомобиль
Условие

Создать класс Car, который хранит марку, модель, год выпуска и текущую скорость автомобиля.

Реализовать методы:

accelerate() — увеличение скорости;

stop() — остановка автомобиля.

🔍 Разбор задания

При создании объекта автомобиля в конструктор передаются:

марка автомобиля;

модель;

год выпуска.

Начальная скорость устанавливается равной 0 км/ч.

При вызове метода accelerate() к текущей скорости прибавляется указанное значение.

При вызове метода stop() скорость автомобиля устанавливается в 0.

Фрагмент кода
class Car:
    def __init__(self, brand, model, year):
        self.brand = brand
        self.model = model
        self.year = year
        self.speed = 0

    def accelerate(self, value):
        self.speed += value
        print(f"Скорость увеличена до {self.speed} км/ч")

    def stop(self):
        self.speed = 0
        print("Автомобиль остановлен")

🖥️ Демонстрация работы — Тест 1

Создаётся автомобиль:

car = Car("Toyota", "Camry", 2023)


Затем выполняются операции:

car.accelerate(20)
car.stop()

✔ Результат работы
Скорость увеличена до 30 км/ч
Скорость увеличена до 50 км/ч
Автомобиль остановлен

Результат

Программа корректно создаёт объект автомобиля, изменяет его скорость с помощью метода accelerate() и устанавливает скорость в 0 при вызове stop().

🛒 СЛАЙД 3: Задание №2 — Корзина покупок
Условие

Создать класс ShoppingCart для хранения товаров в корзине.

Для каждого товара необходимо хранить:

название;

цену;

количество.

Реализовать методы:

add_item() — добавление товара;

total() — вычисление общей стоимости;

show_cart() — вывод содержимого корзины.

🔍 Разбор задания

В классе создаётся список items, в котором хранятся товары.

Каждый товар представлен в виде словаря:

{
    "name": "Хлеб",
    "price": 300,
    "quantity": 2
}


Общая стоимость каждого товара определяется по формуле:

Стоимость = Цена × Количество

Общая сумма корзины рассчитывается с помощью функции sum().

Фрагмент кода
class ShoppingCart:
    def __init__(self):
        self.items = []

    def add_item(self, name, price, quantity):
        self.items.append({
            "name": name,
            "price": price,
            "quantity": quantity
        })

    def total(self):
        return sum(
            item["price"] * item["quantity"]
            for item in self.items
        )

Результат

Программа корректно добавляет товары в корзину, отображает их количество и стоимость, а также рассчитывает итоговую сумму покупки.

💳 СЛАЙД 4: Задание №3 — Электронный кошелёк
Условие

Создать класс ElectronicWallet, который позволяет:

защищать операции PIN-кодом;

пополнять баланс;

выполнять оплату;

переводить деньги другому кошельку;

проверять баланс;

просматривать историю операций.

🔍 Разбор задания

В классе используются приватные атрибуты:

self.__balance
self.__pin
self.__history


Двойное подчёркивание используется для ограничения прямого доступа к этим данным.

Для проверки PIN-кода используется метод:

def check_pin(self, pin):
    return pin == self.__pin

Основные операции

Пополнение:

self.__balance += amount


Оплата:

self.__balance -= amount


Перевод:

self.__balance -= amount
other_wallet.__balance += amount


Каждая успешная операция записывается в историю.
