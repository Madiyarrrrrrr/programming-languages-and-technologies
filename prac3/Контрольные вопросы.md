## Контрольные вопросы

 1. **Что такое ООП?**\
    ООП — объектно-ориентированное программирование. Это подход к программированию, при котором программа состоит из объектов, объединяющих данные и методы для работы с ними.
2. **Что такое класс и объект?**\
    **Класс** — это шаблон или описание объекта. **Объект** — конкретный экземпляр этого класса.
3. **Чем класс отличается от объекта?**\
    Класс задаёт структуру и поведение, а объект создаётся на основе класса и содержит конкретные значения данных.
4. **Что такое атрибут и метод?**\
    **Атрибут** — это данные, которые принадлежат объекту. Например, `brand` и `speed` в классе `Car`.\
    **Метод** — функция внутри класса, которая выполняет действие над объектом, например `accelerate()` или `stop()`.
5. **Для чего используется `__init__()`?**\
    Метод `__init__()` автоматически вызывается при создании объекта. Он используется для первоначальной настройки его атрибутов.
6. **Что означает `self`?**\
    `self` — ссылка на текущий объект класса. Через него получают доступ к атрибутам и методам объекта.
7. **Как создать объект класса?**\
    Объект создаётся путём вызова класса. Например:

   ```
   car = Car("Toyota", "Camry", 2023)
   ```
    Здесь `car` — объект класса `Car`.
8. **Что такое состояние объекта?**\
    Состояние объекта — это текущие значения его атрибутов. Например, для автомобиля состояние может включать марку, модель, год выпуска и текущую скорость.
9. **Что такое инкапсуляция?**\
    Инкапсуляция — принцип ООП, при котором внутренние данные объекта скрываются или ограничиваются от прямого доступа, а взаимодействие с ними происходит через методы.
10. **Что означает атрибут вида `__balance` в Python?**\
     Двойное подчёркивание перед именем атрибута используется для его сокрытия от обычного прямого доступа. Например, `__balance` — приватный атрибут баланса электронного кошелька. Python реализует это через механизм **name mangling**.
11. **Почему состояние объекта удобно изменять через методы?**\
     Методы позволяют контролировать изменение данных и устанавливать необходимые условия. Например, в `ElectronicWallet` деньги можно списать только при правильном PIN-коде и достаточном балансе. Это повышает безопасность и предотвращает неправильное изменение состояния объекта.
