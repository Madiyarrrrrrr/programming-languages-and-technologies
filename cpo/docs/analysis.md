
# Исследование предметной области

## 1. Описание проблемы

В офисах сотрудники проводят совещания в общих переговорных комнатах.
При ручном составлении расписания могут возникать двойные брони,
ошибки во времени и сложности при поиске свободного помещения.

## 2. Существующие решения

### Microsoft Outlook Room Finder
Позволяет искать доступные переговорные при планировании встреч.

Источник:
https://support.microsoft.com/en-gb/outlook/use-the-scheduling-assistant-and-room-finder-for-meetings

### Skedda
Предлагает инструменты для бронирования помещений и управления
их доступностью.

Источник:
https://www.skedda.com/platform/meeting-room-booking-system

### Robin
Предоставляет инструменты бронирования переговорных
и работы с корпоративными календарями.

Источник:
https://robinpowered.com/platform/room-scheduling

## 3. Целевая аудитория

Основные пользователи:
- сотрудники офиса;
- администраторы;
- руководители команд.

## 4. Ограничения

Нельзя создать две пересекающиеся брони одной комнаты.
Время окончания должно быть позже начала.
Прошедшие даты не принимаются.

Данные сохраняются в браузере пользователя.
Без серверной базы записи не синхронизируются
между разными устройствами.

## 5. Актуальность

Веб-приложение позволяет упростить бронирование,
уменьшить количество ошибок и быстрее получать информацию
о занятости переговорных комнат.

## 6. Вывод

В результате проектирования определены основные требования
к системе бронирования. Веб-интерфейс позволяет создавать,
просматривать и отменять бронирования с проверкой конфликтов.
