📐 СЛАЙД 2: Задание №3 — Прямоугольник

Условие: Введите длину и ширину прямоугольника. Определите площадь, периметр и длину диагонали.

🔍 Разбор слайда — алгоритм и математика

Для вычисления площади используется формула:

S = a * b

Для вычисления периметра:

P = 2 * (a + b)

Для вычисления диагонали используется теорема Пифагора:

d = √(a² + b²)

Фрагмент кода:

S = length * width
P = 2 * (length + width)
diagonal = math.sqrt(length ** 2 + width ** 2)

print(f"Площадь (S): {S:.2f}")
print(f"Периметр (P): {P:.2f}")
print(f"Диагональ: {diagonal:.2f}")

🖥️ Демонстрация работы — Тест 1:

► Введите длину прямоугольника: 5.5
► Введите ширину прямоугольника: 4

✔ Результаты вычислений:
• Площадь (S) : 22.00
• Периметр (P) : 19.00
• Диагональ : 6.80

Результат: программа корректно рассчитывает площадь, периметр и диагональ прямоугольника.

💰 СЛАЙД 3: Задание №13 — Заработная плата и премия

Условие: Введите заработную плату и процент премии. Рассчитайте премию, зарплату с премией и сумму подоходного налога 10%.

🔍 Разбор слайда — математические вычисления

Для вычисления размера премии используется формула:

Премия = Зарплата × Процент премии / 100

Зарплата с премией:

Зарплата с премией = Зарплата + Премия

Подоходный налог составляет 10% от зарплаты с премией:

Налог = Зарплата с премией × 10 / 100

Фрагмент кода:

bonus = salary * bonus_percent / 100
salary_with_bonus = salary + bonus
income_tax = salary_with_bonus * 10 / 100

print(f"Премия: {bonus:.2f}")
print(f"Зарплата с премией: {salary_with_bonus:.2f}")
print(f"Подоходный налог 10%: {income_tax:.2f}")

🖥️ Демонстрация работы — Тест 2:

► Введите заработную плату: 200000
► Введите процент премии: 15

✔ Результаты вычислений:
• Премия : 30000.00
• Зарплата с премией : 230000.00
• Подоходный налог 10%: 23000.00

Результат: программа корректно рассчитывает размер премии, заработную плату с учетом премии и подоходный налог.

🔢 СЛАЙД 4: Задание №18 — Пятизначное число

Условие: Введите пятизначное число. Найдите сумму его цифр и сформируйте число с обратным порядком цифр. Строки и циклы не использовать.

🔍 Разбор слайда — целочисленная математика

Для получения отдельных цифр используются операции целочисленного деления // и остатка от деления %.

Фрагмент кода:

ten_thousands = num // 10000
thousands = (num % 10000) // 1000
hundreds = (num % 1000) // 100
tens = (num % 100) // 10
units = num % 10

sum_digits = (
    ten_thousands
    + thousands
    + hundreds
    + tens
    + units
)

reversed_number = (
    units * 10000
    + tens * 1000
    + hundreds * 100
    + thousands * 10
    + ten_thousands
)


При выполнении задания строки и циклы не используются. Все операции выполняются непосредственно над числом.

🖥️ Демонстрация работы — Тест 3:

► Введите пятизначное целое число: 12345

✔ Результаты вычислений:
• Сумма цифр : 15
• Обратное число : 54321

Результат: цифры пятизначного числа успешно обработаны с помощью арифметических операций, а число сформировано в обратном порядке.
